# Ibraz Markets

Live crypto, gold and Bitcoin insights priced in USD and Rupiah. One static page, no build step.

## Data sources
- Binance public market data (`data-api.binance.vision`) — prices, 30-day and 12-month charts, monthly history
- ExchangeRate-API (`open.er-api.com`) — USD/IDR, daily
- Alternative.me — Crypto Fear & Greed index
- mempool.space — Bitcoin block height for the halving countdown

All sources are free, keyless and called from the browser. Prices refresh every 60 seconds.

## Deploy
Served by GitHub Pages from the `main` branch root.

Information only. Nothing here is a recommendation to buy or sell any asset.
